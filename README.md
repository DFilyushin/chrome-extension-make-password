Простое расширение для Chrome генерации безопасных паролей различных типов.

## Возможности
- Настраиваемый сложный пароль
- Генерация запоминаемого пароля из английских слов
- Генерация пин-кодов
- Копирование в буфер обмена

## Поддержка языков
